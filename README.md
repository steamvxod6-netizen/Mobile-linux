# MobileLinux

Мини-терминал на Java для Android (запускается в JavaDroid, Termux и любой среде с Java 11+).
Ранняя версия — возможны ошибки.

A small terminal written in Java for Android (JavaDroid, Termux, or anything with Java 11+). Early version — bugs are possible.

## Запуск / Run

```
java MobileLinux.java
```

В Termux сначала: `pkg install openjdk-17`. Список команд внутри программы: `help`, подробности по одной команде: `help li`.

## Команды / Commands

**Файлы и папки**

| Команда | Что делает |
|---|---|
| `where` | показать, в какой папке ты сейчас |
| `go <имя>` | войти в папку или открыть файл; `go ..` — назад; `go` — в начальную папку |
| `li [-a] [-l]` | что лежит в папке (`папка` / `файл`); `-a` — скрытые, `-l` — подробно |
| `newdir <имя>` | создать папку |
| `newfile <имя>` | создать пустой файл |
| `creato <файл>` | создать файл (любое расширение) и открыть редактор |
| `view <файл>` | показать содержимое файла |
| `copy <откуда> <куда>` | копировать файл или папку |
| `move <откуда> <куда>` | переместить или переименовать |
| `del [-r] <имя>` | удалить файл; `-r` — папку со всем внутри (спросит Y/N) |

**Система**

| Команда | Что делает |
|---|---|
| `me` | имя пользователя |
| `sysinfo` | информация о системе |
| `now` | дата и время |
| `disk` | сколько места на диске |
| `mem` | сколько памяти (RAM) |
| `hist` | история введённых команд |
| `cls` | очистить экран |
| `allow` | проверить доступ к памяти телефона (Android) и подсказать, как его включить |

**Сеть**

| Команда | Что делает |
|---|---|
| `check <сайт>` | проверить связь с сайтом (TCP-соединение, не ICMP) |
| `fetch <адрес>` | показать ответ сайта |
| `get <адрес> [имя]` | скачать файл в текущую папку |
| `net` | сетевые интерфейсы и IP-адреса |
| `conns` | сетевые соединения (если Android разрешает их читать) |

**Пакеты и запуск**

| Команда | Что делает |
|---|---|
| `download pkt python` | установить пакет python (Jython 2.7.4) |
| `download pkt javascript` | установить пакет javascript (Rhino 1.7.15) |
| `update` / `upgrade` | проверить список пакетов / обновления |
| `search [слово]` | поиск пакетов |
| `list` | установленные пакеты |
| `show <пакет>` | информация о пакете |
| `remove <пакет>` | удалить пакет |
| `start python <файл.py>` | найти файл и запустить (`start javascript <файл.js>`, `start js …`) |
| `python <файл.py>` | запустить Python напрямую |

**Прочее:** `help [команда]`, `exit`.

## Редактор creato

Внизу экрана всегда есть подсказка.

- **`,,`** (две запятые) — включить режим команд
- в режиме команд: **Q** — сохранить, **X** — выйти, **N** — новый файл
- **`..`** (две точки) — вернуться к тексту
- Работают также стрелки, Home, End, PgUp, PgDn

## Пакеты

Пакеты скачиваются с Maven Central (`repo1.maven.org`), нужен интернет. Если рядом лежит
файл пакета (`jython-standalone*.jar` или `rhino-1*.jar`), он будет использован вместо скачивания.

- **python** — [Jython](https://www.jython.org/) 2.7.4. Это **Python 2.7** на Java: `print("текст")`
  работает, f-строк нет. Если в файле есть не-латинские буквы, первой строкой добавь:
  `# -*- coding: utf-8 -*-`
- **javascript** — [Rhino](https://mozilla.github.io/rhino/) 1.7.15 (JavaScript на Java). Вывод —
  через `console.log("текст")` (внутри Rhino есть ещё `print`).
